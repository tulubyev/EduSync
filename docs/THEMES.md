# Темы оформления (#45)

Светлая, тёмная и «как в системе» (`prefers-color-scheme`). Выбор — в боковом меню под языком и в «Настройках» → «Оформление».

## Где хранится
- В браузере: `localStorage['myepa-theme']`. `client/public/theme-init.js` ставит класс `.dark` на `<html>` до отрисовки — без вспышки светлого фона.
- В профиле: `user_settings.theme` (`light` / `dark` / `system`), `GET/PUT /api/profile/theme`. После входа кабинет берёт тему из профиля, поэтому она переходит между устройствами. SQL не нужен — колонка была в схеме.
- Логика на клиенте — `client/src/theme.ts` (`useTheme`, `setTheme`), список тем — `shared/themes.ts`.

## Как устроены цвета
- Компоненты shadcn и новые экраны — на токенах: `bg-background`, `bg-card`, `text-foreground`, `text-muted-foreground`, `border`. Значения — переменные в `client/src/index.css` (`:root` и `.dark`).
- Старые экраны с жёсткими классами (`bg-white`, `text-gray-800`, `bg-red-50`, `border-gray-200`…) в тёмной теме перекрашивает `client/src/theme-dark.css`. Файл создаёт `node scripts/gen-dark-theme-css.cjs` из палитры Tailwind — руками не править.
- Нативные поля без своего фона в тёмной теме получают `--background` (правило в `index.css`).

## Островки светлой темы
Класс `light-island` возвращает светлые переменные и отключает перекраску внутри. Так оставлены экраны на инлайн-стилях: панель администратора и форма входа на фиолетовом фоне. Новые экраны так делать не нужно — пишите на токенах.
