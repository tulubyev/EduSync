# Подсказка записать вебинар в неудобное время

Задача #48. My EPA сам предлагает записать вебинар через сервис записи (Help Recorder), если ученику неудобно его
смотреть вживую. Запись идёт той же формой «Записать трансляцию», что и кнопка «Не смогу прийти → Записать».

## Когда время «неудобное»

`shared/recordingHints.ts` (тесты `recordingHints.test.ts`), причины по порядку:

1. **Пересечение** с уроком, вебинаром или экзаменом в календаре (дедлайны и отменённое не мешают, встык — не пересечение).
2. **Рабочее время** — если ученик его указал: рабочие дни (по умолчанию пн–пт) и часы.
3. **Вне удобных часов** — по умолчанию 08:00–22:00; вебинар через полночь — всегда вне.

Время считается в часовом поясе, выбранном в кабинете. Подсказка только у будущих вебинаров со ссылкой входа,
которые ещё не записываются и не отменены, и только если ученик не выключил подсказки.

## Где видно

- Карточка вебинара (календарь, «Сегодня»): «Неудобное время: <причина>» и кнопки «Записать» / «Не предлагать».
  «Не предлагать» запоминается в браузере для этого вебинара.
- «Сегодня» на главной: «Вебинаров в неудобное время на этой неделе: N» со списком тех, что не показаны карточками.
- «Записать все (N)» — в блоке на главной и в календаре (для показанной недели или месяца), если таких вебинаров
  больше одного. Окно со списком (все отмечены), одно подтверждение права на запись на все, итог по каждому:
  запланировано / уже записывается или прошло / ошибка Help Recorder (например, исчерпан лимит тарифа).
  API `POST /api/recording/from-events` `{ eventIds, rightsConfirmed: true }` — данные записи берутся из событий
  ученика, а не из запроса; чужие события — `not_found`, без ссылки, прошедшие и уже записанные — `not_recordable`.
- Напоминание на главной: вебинар со ссылкой входа начнётся в ближайшие 2 часа и ещё не записывается —
  «Не успеваете? Записать» или «Приду» (скрывает и напоминание, и подсказку для этого вебинара).
  Правило — `soonWebinars` в `shared/recordingHints.ts`, с тестами.
- «Настройки» → «Удобное время»: удобные часы, рабочее время (пн–пт), выключатель подсказок.
  Хранится в `user_settings` (`comfort_from`, `comfort_to`, `work_from`, `work_to`, `work_days`, `recording_hints`;
  минуты от полуночи), API `GET/PUT /api/profile/schedule`.
