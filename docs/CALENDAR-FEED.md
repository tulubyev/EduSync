# Расписание в Google, Яндекс, Apple и Outlook

Задача #18, шаг 1: ученик подписывает свой календарь на ленту My EPA по секретной ссылке. Календарь сам
перечитывает ленту: уроки, вебинары, задания, экзамены и дедлайны появляются и обновляются без участия ученика.

## Как пользоваться

«Календарь» → «Подписаться» → «Создать ссылку», затем:

- **Google Calendar** — кнопка «Добавить в Google Calendar» (открывает Google с подпиской). Вручную: «Другие календари»
  → «+» → «Добавить по URL».
- **Apple Календарь, Outlook** — кнопка со ссылкой `webcal://…`.
- **Другие календари (Яндекс и др.)** — пункт «Добавить по ссылке» / подписка по URL, вставить ссылку.

Google перечитывает подписки раз в несколько часов (это решает Google, ускорить нельзя), Apple и Outlook — чаще.
Мгновенная двусторонняя синхронизация через Google Calendar API — следующий шаг #18, по желанию.

## Как устроено

- Адрес: `https://<сайт>/api/calendar/<секрет>.ics`; секрет — 256 бит (`users.calendar_token`, уникальный индекс).
  Ссылка открывает расписание без входа, поэтому ученик может её перевыпустить (старая сразу перестаёт работать)
  или отключить. В ответы API (профиль, панель) секрет не попадает.
- `server/routes/calendar.ts` — создание, перевыпуск, отключение (`/api/calendar/feed`, за входом) и сама лента.
  Общий лимит запросов по IP на ленту не действует: календари забирают её с общих адресов Google и Apple.
- `server/services/icalFeed.ts` — чистая сборка `.ics` по RFC 5545 (тесты `icalFeed.test.ts`):
  - события за 30 дней назад и год вперёд, время в UTC;
  - тип события и подписи — на языке ученика (`users.language`);
  - у срока без длительности событие длится 30 минут и заканчивается в момент дедлайна, время не занимает
    (`TRANSP:TRANSPARENT`); уроки и вебинары без длительности — час;
  - ссылка входа на вебинар — в `LOCATION` и `URL`, ссылки на урок и материалы — в описании (только http/https);
  - выполненное отмечено «✓», отменённое — `STATUS:CANCELLED` (календари его убирают).
- Клиент: `client/src/components/events/CalendarFeedDialog.tsx`, тексты — словарь `calendarFeed`.
