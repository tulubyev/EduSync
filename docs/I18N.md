# Языки кабинета

Решение владельца (25.10.2026): кабинет на нескольких основных языках. Первые — русский, английский, французский,
немецкий, испанский, итальянский (`shared/languages.ts`).

## Как устроено

- **Словари кабинета** — `client/src/locales/<язык>.ts`. Русский (`ru.ts`) — исходный, остальные повторяют его форму:
  TypeScript не соберёт словарь без нужного ключа, тест `client/src/locales/locales.test.ts` сверяет формы всех языков.
  Строки с подстановками — функции: `hello: (name) => \`Привет, ${name}! 👋\``.
- **В компоненте:** `const { m, lang } = useLang();` → `m.nav.calendar`, `m.common.minutes(45)`.
- **Даты и время** — через `Intl` на языке ученика (`client/src/components/events/eventTime.ts`), без своих списков
  месяцев.
- **Язык ученика** хранится в профиле (`users.language`): задаётся при регистрации языком сайта, меняется
  переключателем в боковом меню (`PUT /api/profile/language`), при входе берётся из профиля.
- **Быстрый ввод** (`shared/learningEvents.ts`) понимает все шесть языков независимо от выбранного.
- **Публичные страницы** пока на русском и английском (`t({ ru, en })` на месте); для остальных языков показывается
  английский, правовые документы — тоже.

## Как добавить язык

1. Код в `LANGS` и название в `LANG_NAMES` (`shared/languages.ts`).
2. Словарь `client/src/locales/<код>.ts` — копия `en.ts` с переводом; подключить в `client/src/locales/index.ts`.
3. При необходимости — слова языка в разборе быстрого ввода (типы событий, «завтра», дни недели, месяцы) и тест.

## Что переведено

| Часть | Статус |
|---|---|
| Меню, главная, «Сегодня», календарь, события, быстрый ввод | 6 языков |
| Курсы, дедлайны, библиотека, настройки, подписка, платформы | следующий шаг |
| Записи, ИИ-помощник, вход и регистрация, публичные страницы | далее |
| Сообщения сервера (ошибки API) | далее — по `Accept-Language` / языку профиля |
| Панель администратора | остаётся на русском |

Переводы сделаны без носителей языка — перед запуском на рынках их стоит вычитать.
