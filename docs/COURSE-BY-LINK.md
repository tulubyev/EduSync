# Добавить курс по ссылке

Задача #19, пункт «без договоров с площадками». Ученик вставляет ссылку на курс с любой площадки (Coursera, Udemy,
edX, Stepik, онлайн-школы) — форма «Добавить курс» заполняется сама: название, описание, обложка, ссылка, площадка.

## Как устроено

- `POST /api/courses/preview { url, lang }` — за входом и строгим лимитом запросов (`rateLimiters.strict`).
- `server/services/coursePreview.ts` — загрузка страницы, `coursePreviewParse.ts` — разбор (тесты):
  OpenGraph → Twitter → JSON-LD `Course` → `<title>` и `meta description`; канонический адрес; обложка — только http(s).
- Площадка — по домену ссылки: сначала адреса сайтов из справочника площадок, затем встроенный список
  (`KNOWN_HOSTS`). Если страница не читается (защита от роботов, ошибка), название берётся из адреса, площадка
  определяется всё равно, форма показывает «проверьте название».

## Защита от SSRF

Сервер ходит по ссылке пользователя, поэтому:

- только `http`/`https`, порты 80 и 443, без логина и пароля в адресе;
- каждый адрес из DNS проверяется (`isPublicAddress`: нет локальных, частных, link-local и служебных сетей,
  IPv6 ULA и link-local, IPv4-mapped), и соединение идёт именно на проверенный адрес — подмена DNS между проверкой
  и запросом не проходит;
- каждый редирект (не больше 4) проверяется заново;
- 8 секунд на ответ, читается не больше 1,5 МБ, только `text/html`.

Тесты: разбор, площадки, адреса (`coursePreviewParse.test.ts`) и загрузка с локального сервера — gzip, редирект,
запрет локальных адресов (`coursePreview.test.ts`).

## Ограничения

- Площадки, которых нет в справочнике, определяются по встроенному списку, но курс сохраняется без площадки
  (в каталоге — «Другие площадки»), пока площадку не добавят в справочник.
- Прогресс и сроки по ссылке не приходят — для этого нужен обмен данными с площадкой (#19, партнёрский API).
