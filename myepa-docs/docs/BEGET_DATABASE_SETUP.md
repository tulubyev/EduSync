# Настройка базы данных PostgreSQL на Beget.com

## Проблема
Приложение получает ошибку аутентификации при попытке подключения к базе данных PostgreSQL на Beget:
```
password authentication failed for user "replit"
```

## Проверьте данные подключения

### 1. Данные из панели управления Beget
Войдите в панель управления на beget.com:
1. Перейдите в раздел **"Базы данных"** → **"PostgreSQL"**
2. Проверьте следующие данные:
   - **Хост** (Host): должен быть вида `xxx.beget.app` 
   - **Имя базы данных** (Database name)
   - **Имя пользователя** (Username)
   - **Пароль** (Password)
   - **Порт** (Port): обычно 5432

### 2. Формат строки подключения
Правильный формат: `postgres://username:password@host:port/database_name`

Пример: `postgres://myuser:mypass@sql.beget.app:5432/mydb`

## Возможные причины ошибки

### 1. Неправильные учетные данные
- Проверьте правильность имени пользователя и пароля
- Убедитесь, что используете данные именно для PostgreSQL (не для MySQL)

### 2. Ограничения доступа
- На Beget может требоваться добавление IP-адреса Replit в список разрешенных
- Проверьте настройки безопасности базы данных в панели управления

### 3. Специальные символы в пароле
- Если пароль содержит специальные символы (@, :, /, %), их нужно закодировать:
  - `@` → `%40`
  - `:` → `%3A`
  - `/` → `%2F`
  - `%` → `%25`

## Шаги для решения

### Шаг 1: Проверьте подключение вручную
Попробуйте подключиться через psql:
```bash
psql "postgres://username:password@host:port/database_name"
```

### Шаг 2: Создайте нового пользователя (если нужно)
В панели Beget:
1. Создайте нового пользователя для PostgreSQL
2. Присвойте ему права на существующую базу данных
3. Используйте новые учетные данные

### Шаг 3: Проверьте настройки безопасности
1. В панели управления Beget найдите настройки PostgreSQL
2. Проверьте, есть ли ограничения по IP-адресам
3. Добавьте IP-адрес Replit, если требуется

### Шаг 4: Обновите переменные окружения
В Replit Secrets обновите:
- `BEGET_DB_HOST`: хост базы данных
- `BEGET_DB_NAME`: имя базы данных  
- `BEGET_DB_USER`: имя пользователя
- `BEGET_DB_PASSWORD`: пароль (с кодированием спецсимволов если нужно)
- `BEGET_DB_PORT`: порт (обычно 5432)

## Альтернативные решения

### 1. Использование прямой строки подключения
Если отдельные переменные не работают, можно использовать полную строку:
```
DATABASE_URL=postgres://username:password@host:port/database_name
```

### 2. Использование SSL
Некоторые хостинги требуют SSL соединение:
```
DATABASE_URL=postgres://username:password@host:port/database_name?sslmode=require
```

### 3. Создание новой базы данных
Если проблемы продолжаются:
1. Создайте новую базу данных PostgreSQL в панели Beget
2. Создайте нового пользователя с полными правами
3. Используйте новые учетные данные
